# Decision records

Lightweight ADRs. Baseline decisions D1-D10 live in [../PLAN.md](../PLAN.md) section 1 (tracked by issue "decision: D1-D10 baseline"). Add a new record here for any lasting decision made later.

File name: `NNNN-short-title.md` (4-digit, increasing). Create the tracking issue first (`type:decision` label) and reference it.

```markdown
# NNNN: Title
- Status: proposed | accepted | superseded by NNNN
- Issue: #N
- Date: YYYY-MM-DD

## Context
What forces/constraints.
## Decision
What we chose (one paragraph).
## Alternatives considered
Bullets with why not.
## Consequences
What changes; what to verify; follow-up issues.
```
