# apps/alloy

The Alloy application: a Tauri 2 shell (`src-tauri`) hosting a Svelte 5 + TypeScript UI (`ui`). The project
overview is in the [root README](../../README.md); the plan is in [docs/PLAN.md](../../docs/PLAN.md).

```
src-tauri/   Rust: IPC glue to alloy-engine, updater, notifications, Android project (gen/android)
ui/          SvelteKit (static adapter), Svelte 5 runes only, pnpm only
  src/lib/components/   shell, timeline, composer, settings, onboarding, common primitives
  src/lib/stores/       runes stores (rooms, timeline, prefs, notifications, viewport, updates, ...)
  src/lib/ipc/          typed client: Tauri IPC, the dev WebSocket bridge (`?engine=ws://...`) or a mock
  src/lib/generated/    TypeScript types generated from alloy-protocol (do not edit)
  src/lib/theme/        design tokens -> CSS variables (generated by `gen-css`)
  scripts/e2e-bridge.mjs  full-stack browser E2E (desktop, and E2E_MOBILE=1 phone audit)
```

## Commands

Tauri commands run from `apps/alloy` (its `package.json` forwards to the CLI in `ui/`); UI commands run in `ui/`.

```bash
pnpm install && (cd ui && pnpm install)
pnpm tauri dev                                            # desktop app against a real homeserver
pnpm tauri build                                          # desktop bundles
pnpm tauri android build --apk --debug --target aarch64   # Android debug APK
cd ui
pnpm dev                                                  # UI only in a browser, with the mock transport
pnpm check && pnpm test && pnpm build                     # type-check, unit tests, production build
```

Android needs `ANDROID_HOME`, `NDK_HOME` (NDK 27) and the `aarch64-linux-android` Rust target. Release APKs are
signed by `scripts/sign-android-apk.sh`; see [docs/RELEASING.md](../../docs/RELEASING.md).

## Rules for UI code

- Svelte 5 runes (`$state`, `$derived`, `$props`, `$effect`); no legacy syntax.
- Colours, radii and spacing only through `--alloy-*` tokens; layout rhythm lives in `src/lib/layout.css`,
  phone rules in `src/lib/mobile.css`.
- Icons only from `src/lib/icons` (Lucide), sizes 16, 20 or 24; no emoji in source.
- Every labelled control gets a tooltip (audited by a test); every screen must pass the mobile audit
  (no page scroll, no horizontal overflow, 44 px targets under 900 px).
- Every settings control must change real behaviour ([ADR 0004](../../docs/decisions/0004-functional-settings.md)).
